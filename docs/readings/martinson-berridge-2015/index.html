5개
  1. 01검색된 453편 가운데 비판을 핵심으로 삼은 67편을 질적으로 조직한 구성적 문헌고찰이며 메타분석은 아닙니다.
  2. 02비판의 처방은 모델을 확장하기, 노인의 목소리로 개인화하기, 폐기하기, 새 틀과 명칭으로 바꾸기의 네 범주입니다.
  3. 03객관적 기준과 노인의 자기평가는 다를 수 있고 성공의 의미는 문화 사이와 같은 문화 안에서도 다양합니다.
  4. 04기준을 더하고 완화해도 규범적 경계가 남으며 개인의 성취 강조는 구조적 기회 불평등을 가릴 수 있습니다.
  5. 05결론은 이상적인 개인을 선별하기보다 다양한 사람이 자기 방식대로 번영할 사회적 조건을 만들자는 제안입니다.
