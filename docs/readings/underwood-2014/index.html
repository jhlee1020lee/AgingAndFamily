5개
  1. 01Lothian Birth Cohorts는 같은 사람의 11세 인지능력과 노년기 인지·건강·뇌 자료를 잇는 드문 종단자료입니다.
  2. 0211세 점수는 77세 지능 개인차의 약 절반과 관련됐지만 개인의 능력이 절반 결정됐다는 뜻은 아닙니다.
  3. 03아동기 인지능력을 고려하자 일부 생활방식과 노년기 인지의 상관이 사라져 선택효과의 중요성이 드러났습니다.
  4. 04나머지 개인차에는 교육, 건강, 환경과 노년기의 서로 다른 인지 변화가 계속 관여할 수 있습니다.
  5. 05뇌 연결성과 인지예비력도 초기 수준과 이후 변화를 구분해야 하며 노년기 학습 가능성을 배제하지 않습니다.
