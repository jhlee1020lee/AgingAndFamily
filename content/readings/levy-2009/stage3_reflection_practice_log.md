# Levy 읽기 소감과 후속 문답 시범 적용

- 작업일: 2026-09-06
- 범위: Levy(2009) 한 편의 교수님 답변 대비 단계.
- 사용자 요청: 첫 답변은 흥미로운 점 또는 개인 경험에서 출발한다. 꼬리 질문은 미리 보이고 답변만 클릭해 확인한다. 대괄호 속 경험은 여러 일상 예시 중 버튼으로 바꿔 볼 수 있다.

## 콘텐츠

`professor_prep.json`의 `practice_format`을 `reflection-followups-v1`로 지정하고, `reading-response`를 기본 탭으로 설정했다. 기존 개념·근거 질문 15개는 내부 소스로 보존하고 화면에서는 제외했다.

새 첫 답변은 논문 출발 3개, 경험 출발 3개이며, 각각 후속 질문·답변 3개를 갖는다. 총 18개 후속 문답의 영어·한국어와 원문 근거를 함께 작성했다. 경험형에는 카드당 6개씩 총 18개의 가상 일상 예시를 넣고, 가상 예시임을 화면에 표시했다. 대괄호에는 장면·나이에 관한 말·당시 해석을 넣으며 논문 해석과 근거는 고정한다. 사용자의 실제 경험이라는 사실 주장을 하지 않는다.

| 카드 | 주제 | 검토한 원문 근거 |
|---|---|---|
| levy-reflection-01 | 어릴 때 배운 노인 이미지 | LIFE-001, LIFE-002, SELFREL-001 |
| levy-reflection-02 | 눈치채지 못한 영향 | UNCONSC-001, FUTURE-001 |
| levy-reflection-03 | 7.5년이라는 숫자 | INTRO-002, ABS-001 |
| levy-reflection-04 | 도움과 낮춰 보는 말 | SELFREL-002, SELFREL-001 |
| levy-reflection-05 | 기대와 실제 능력 | PATH-PSYCH-001, PATH-PHYS-001 |
| levy-reflection-06 | 해봐야 소용없다는 생각 | PATH-BEHAV-001, SELFREL-002 |

인용된 종단연구를 Levy(2009)의 단일 실험처럼 소개하지 않았다. 기초 건강 등을 보정한 장기적 관계를 개인에게 보장되는 수명 증가로 바꾸지 않았다. 필체 평가·가상 치료 선택·실험실 점화와 실제 노화·치료·일상 개입 효과를 구분했다. 경험에서 얻은 해석과 연구가 검증한 결과도 구분했다.

## 화면과 동작

- `이 읽기 답변 준비 / 두 편 연결` 두 탭. 새 형식을 처음 접하거나 이전에 저장한 탭이 없어졌으면 ‘이 읽기 답변 준비’를 우선한다. 이후 사용자의 탭 선택과 연습 표시는 유지된다.
- 첫 답변은 바로 보인다. 꼬리 질문 묶음은 기본적으로 열린 native `details`이며, 개별 답변만 닫혀 있다.
- 경험형 카드마다 ‘경험 바꾸기’ 버튼과 예시 이름·순번을 표시한다. 경험 문장만 순환 교체하고 같은 경험을 인용한 후속 답변도 동기화한다. 다른 카드의 선택, 논문 해석, 근거와 답변 펼침 상태는 보존한다.
- 선택한 경험 ID를 카드별로 저장한다. 새로고침·언어 전환에도 유지하고 삭제된 예시 ID는 첫 예시로 대체한다. 저장소가 차단되어도 현재 방문에서 전환할 수 있다.
- 질문·답변 언어를 독립적으로 바꾸며 주제, 경험 안내, 후속 문답도 해당 선택을 따른다. 기본은 한국어다.
- 새 카드·후속 문답은 새 ID를 사용한다. 기존 개념 질문의 연습 표시는 보존한다.
- 새 스타일은 해당 형식 아래로 한정했다. 데스크톱과 모바일에서 기존 테마의 중립색을 사용한다.

## 검토와 확인

- 첫 답 6개·후속 문답 18개를 해당 원문 세그먼트와 대조하고 영어·한국어의 주장 범위를 확인했다. 가상 예시 9개의 완성 영·한 답변과 연결된 후속 답변 3개를 치환해 읽고 문법·주장 범위를 검토했다.
- Levy `professor-prep` 페이지 승인 해시를 재검수 후 갱신했다. 원문·번역·주차 연결 콘텐츠는 변경하지 않았다.
- strict alignment: Levy 16/16 통과.
- source/content 및 built publish gate: Levy의 모든 단계 approved.
- 영문 학습 자료 검사: 22편의 소스 스키마·한국어 병기·근거 ID 통과.
- 상호작용·앱 검사: 기존 22편 대비 페이지, 언어·탭·연습 표시와 새 후속 문답 검사 통과.
- 새 스키마와 렌더 위치·근거·경험 슬롯·초기 표시·승인 해시 회귀 검사 75개, 전체 validation gates 127개, build contracts 28개 및 주차 연결 135개 검사 통과.
- 사이트 링크: 276 HTML 페이지, 비공개 경로 노출 없음.
- 모바일 계약: 360/390/430px 통과. 초기 CSS 최종층 검사 실패는 새 스타일 블록을 최종 모바일 계약 안으로 옮겨 해결했다.
- 실제 Chrome에서 데스크톱 1440px와 모바일 360px의 질문 초기 표시·답변 펼치기·경험 전환·연결된 후속 답변·새로고침 저장·레이아웃을 확인했다. 모바일 가로 넘침 없음. 앱 회귀 검사에서 영·한 전환과 카드별 독립성, 순환, 저장 복원, HTML 문자 그대로 표시도 확인했다.

공유 자산 갱신으로 생성된 다른 대비 페이지와 주차 페이지의 CSS·JavaScript 버전 URL도 갱신되었다. 다른 읽기의 답변 콘텐츠는 변경하지 않았다. 이 작업은 로컬 HTML 시범 적용이며 GitHub 배포는 실행하지 않았다.

## 경험 예시 추가

사용자의 추가 요청에 따라 기존 카드당 3개 뒤에 3개씩 더했다. 기존 9개 예시의 ID·내용·순서를 유지하며 다음 9개를 추가했다.

- 도움과 낮춰 보는 말: 명절 음식 준비, 가족 여행 계획, 가족 보드게임.
- 기대와 실제 능력: 회의 발표 연습, 탁구 모임 참여, 영어 회화 연습.
- 해봐야 소용없다는 생각: 쉬는 시간 스트레칭, 수면 습관 이야기, 금연 상담 안내.

새 예시 9개의 완성 영어·한국어 문장과 연결된 후속 답변을 읽고 원문 근거 세그먼트의 주장 범위를 확인했다. 승인 해시를 재검수 후 갱신하고 Levy만 빌드했다. 고정 답변과 기존 예시, 다른 읽기 콘텐츠가 변경되지 않았음을 작업 전후 해시로 확인했다.

이번 추가분은 strict alignment 16/16, source/content와 built publish gate, Levy 앱 검사, 전체 모바일 계약 검사를 통과했다. 생성 HTML에서 18개 예시 전체의 영·한 슬롯, 연결된 후속 답변, 순번과 한 바퀴 순환을 확인했다. 실제 데스크톱·모바일에서도 새 예시 표시와 기존 선택 유지를 확인했다.

## 단일 읽기와 공통 연결 답변의 두 탭으로 정리

사용자 요청에 따라 Levy의 별도 개념·근거 질문 탭과 패널을 생성 HTML에서 제거하고 첫 탭을 ‘이 읽기 답변 준비’로 바꿨다. 내부 개념 문항 15개는 원본 JSON에 보존한다. ‘두 편 연결’은 기존 주차별 공통 데이터와 저장 상태를 그대로 사용한다. 다른 읽기에는 새 두 탭 형식을 적용하지 않았다.

필요한 개념은 꼬리 질문에서 다룬다. 중복된 개입 지속성 질문인 `levy-reflection-05-followup-03`을 생리적 경로 문답으로 교체하고 `PATH-PHYS-001`의 스트레스 반응과 대조했다. 실험의 단기 반응을 장기 건강 차이의 완전한 설명으로 단정하지 않았다. 첫 답변 6개, 후속 문답 18개, 가상 경험 18개는 유지했다.

승인 재검수·빌드 후 strict alignment 16/16, source/content와 built publish gate, 전체 앱 검사(447개 공개 대비 답변), 상호작용 검사, 빌드 계약 28개 및 주차 연결 135개를 통과했다. 두 탭·콘텐츠 렌더 회귀 검사 87개를 통과했다. 이전 cold-call 탭·링크에서 첫 탭으로 돌아오는 동작과 기존 경험·연습 표시 보존도 확인했다. 사이트 링크 276개 HTML/11,839개 대상과 모바일 계약 360/390/430px를 확인했다. 실제 1440px 데스크톱과 360px 모바일에서 두 탭 표시·전환·질문 초기 상태·가로 넘침 없음을 확인했다.

## 모바일 세로 길이 조정

모바일에서 지나치게 길다는 사용자 피드백을 확인했다. 390px 화면에서 첫 카드까지 약 1,012px, 첫 경험 카드 높이 약 1,206px였고, 중첩 패널 여백 때문에 본문 폭이 약 277px로 좁아져 있었다.

560px 이하의 Levy 교수님 답변 대비 화면에만 제목·상단 여백을 줄이고, 바깥 패널의 중첩 여백을 제거했다. 언어 선택과 두 탭의 숫자 배지, 연습 표시와 경험 전환 버튼을 가로로 배치했다. 문단·안내·질문의 불필요한 간격을 줄이고 근거를 펼칠 때는 본문 폭을 모두 쓰도록 했다. 첫 답변·꼬리 질문·경험 예시를 숨기거나 요약하지 않았다.

390px에서 같은 상태로 비교한 결과 첫 카드 위치는 약 602px, 첫 경험 카드 높이는 약 881px, 본문 폭은 약 322px가 되었다. 전체 페이지 높이는 7,629px에서 5,557px로 약 27% 줄었다. 본문 글자 크기는 16.32px로 유지했고, 버튼·질문 펼치기의 최소 터치 높이도 44px로 유지했다.

CSS만 변경해 내용 승인 해시는 그대로 유효하다. Levy 빌드 후 strict alignment 16/16, source/content 및 built publish gate, 모바일 계약 360/390/430px, 사이트 링크 검사를 통과했다.

실제 브라우저의 360/390/430px 화면에서 한국어·영어 답변, 경험 교체와 연결된 꼬리 답변, 공통 두 편 연결 탭을 확인했다. 가로 넘침이 없고, 360px에서도 언어 선택이 같은 행에 있으며 경험 버튼 높이는 44px였다. 1440px 데스크톱에서는 기존 제목 크기와 패널 여백이 유지됨을 확인했다.
