# 교수님 질문 스타일 프로필

이 문서는 같은 담당교수의 2026년 1학기 성인발달과 노화 수업에서 확인된 질문 형식을 새 과목의 학습문항 설계에 제한적으로 활용하기 위한 내부 기준입니다. 과거 강의의 내용은 새 과목 정답의 근거가 아닙니다.

## 관찰된 형식

- 짧은 퀴즈 안에서 OX, 객관식, 단답, 복수선택을 섞습니다.
- 한두 단어만 바꾼 문장이나 그럴듯하지만 논문에 없는 변수를 오답으로 사용합니다.
- 같은 개념을 정의, 구분, 사례 적용의 다른 형식으로 반복 확인합니다.
- 한국어 설명과 함께 정확한 영어 용어를 요구할 수 있습니다.
- 논문의 큰 결론뿐 아니라 연구설계, 변수, 비교대상, 한계를 읽었는지 확인합니다.
- 서술형·구술형에서는 `정의 → 유사개념 구분 → 사례/가족/정책 적용` 흐름이 반복됩니다.
- 읽기 첫 질문은 대체로 `무엇이 새로웠는가 → 왜 그렇게 느꼈는가 → 읽기 전 생각과 무엇이 달라졌는가`의 순서로 이어집니다.
- 첫 답변 뒤에는 정확한 개념명, 논문의 구체적 근거, 인과와 연관의 구분, 한계와 한국 가족 적용을 다시 묻는 경향이 있습니다.
- 모호하거나 질문에서 벗어난 답에는 핵심을 한 문장으로 다시 말하도록 요구하는 교정 질문이 뒤따릅니다.

## 새 사이트 적용 규칙

- 모든 정답은 현재 논문의 `evidence_segment_id`에 연결합니다.
- 과거 스타일을 반영한 문항에는 데이터에서 `style_basis: "prior-course-pattern"`을 표시합니다.
- 논문에 직접 쓰이지 않은 적용 질문은 `question_scope: "application"`으로 구분합니다.
- 교수님 답변 대비는 `이 읽기 답변 준비`와 같은 주차의 공통 `두 편 연결` 두 탭으로 구성합니다. 별도 개념·근거 질문 탭은 사용하지 않고 필요한 개념과 연구설계·근거·한계를 첫 답변 아래 꼬리 질문에 담습니다.
- 개별 읽기는 논문에서 출발하는 첫 답변 3개와 경험에서 출발하는 첫 답변 3개를 기본으로 합니다. 각각 꼬리 질문·답변 3개 이상을 준비하며, 질문 목록은 처음부터 보이고 답변만 클릭해 엽니다.
- 경험형 카드마다 교체 가능한 가상 일상 예시를 최소 6개씩 준비합니다. 예시는 사실로 확인한 사용자 경험으로 서술하지 않으며 가상임을 표시합니다. 장면·관련 단서·당시 해석만 교체하고 논문의 해석과 원문 근거는 유지합니다.
- 질문과 답변은 한국어를 기본으로 하되 독립적으로 영어를 선택할 수 있게 합니다. 모바일에서는 본문 크기와 터치 영역을 유지하며 상단·중첩 여백을 줄입니다.
- 모바일의 세로 길이를 고려해 제목과 질문은 한 가지 요구로 짧게 쓰고, 첫 답에는 관점과 흥미로웠던 이유를 담습니다. 자세한 수치·연구설계·해석의 한계는 아래 꼬리 답에 충분히 남깁니다. 경험 슬롯을 모두 채운 문장도 화면에서 확인하며 내용 생략이나 글자 축소로 길이를 맞추지 않습니다.
- 이전 학기 보정 STT는 질문 순서를 추상화하는 데만 사용하며 문장, 학생 경험, 개인정보를 답변에 옮기지 않습니다.
- 이번 학기 실제 슬라이드·퀴즈·녹음이 생기면 과거 패턴의 가중치를 낮추고 현재 근거로 교체합니다.
- 과거 녹음, STT, 학생 이름, 출석·사담 내용은 사이트나 저장소에 복사하지 않습니다.
